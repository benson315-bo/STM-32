# STM32 拆炸彈模擬系統
使用 NUCLEO-G474RE，結合 LED、按鈕、UART、PWM 與蜂鳴器，模擬限時解除警報的互動遊戲。

## 1. 情境故事
玩家需要在 30 秒內，透過電腦輸入正確的解除指令。
輸入錯誤時，LED 閃爍加快、呼吸燈亮度上限提高。
時間到或累計錯誤 5 次，系統進入失敗狀態。
本專題為燈光與聲音的遊戲模擬。

## 2. 替身對照
- PC8 LED：模擬倒數中的警示燈。
- PC6 呼吸燈：模擬危險程度，錯誤越多，亮度上限越高。
- PB1 蜂鳴器：模擬失敗時的聲音警報。
- PC13 按鈕：提供立即停止功能。
- 電腦串口程式：模擬解除警報的操作終端。

## 3. 功能與驗收條件

| 操作或條件 | 預期結果 | 實測結果 |
|---|---|---|
| 系統啟動 | 開始 30 秒倒數，PC8 閃爍，PC6 顯示呼吸效果 | 待填 |
| 輸入正確解除指令 | LED 熄滅，停止倒數與警報 | 待填 |
| 輸入錯誤指令 | 錯誤次數增加，閃爍加快，呼吸燈亮度上限提高 | 待填 |
| 累計錯誤 5 次 | 兩顆 LED 全亮，蜂鳴器鳴叫約 2 秒 | 待填 |
| 倒數時間結束 | 兩顆 LED 全亮，蜂鳴器鳴叫約 2 秒 | 待填 |
| 按下 PC13 | 立即關閉 LED 與蜂鳴器，停止計時 | 待填 |

## 4. 用到的技術
- GPIO：控制警示 LED 與蜂鳴器。
- EXTI 外部中斷：偵測 PC13 按鈕。
- UART：透過 USART1 與電腦交換訊息。
- Timer：產生計時或週期事件，實際用途依程式設定。
- PWM：透過 TIM3 控制 PC6 LED 的亮度。
- RCC／時脈設定：提供處理器與周邊所需時脈。

## 5. 腳位表

| 腳位／周邊 | 用途 |
|---|---|
| PC8 | 主警示 LED |
| PC6／TIM3_CH1 | PWM 呼吸 LED |
| PB1 | 蜂鳴器控制 |
| PC13 | 板上按鈕，立即停止系統 |
| USART1 TX | 傳送訊息到電腦，實際腳位依 teat3.ioc |
| USART1 RX | 接收電腦指令，實際腳位依 teat3.ioc |
| GND | 外接元件與串口轉接器共地 |

LED 串接限流電阻。
外接蜂鳴器的供電與驅動方式，需配合元件規格。

## 6. 建置與執行

### 開發環境
- STM32CubeIDE
- NUCLEO-G474RE 開發板
- USB 傳輸線
- 支援 3.3V 邏輯的 USB-UART 轉接器
- 串口終端程式，或本專題搭配的 Python 串口工具

### 匯入與燒錄
1. 下載並解壓縮本專案，或使用 Git 複製。
2. 在 STM32CubeIDE 選擇：
   File → Import → General → Existing Projects into Workspace。
3. 選取包含 .project 的專案資料夾。
4. 開啟 teat3.ioc，確認腳位與周邊設定。
5. 執行 Build Project。
6. 透過 ST-LINK 將程式燒錄至開發板。

### 串口設定
- 使用 USART1。
- 波特率：115200。
- 資料位元：8。
- 同位檢查：None。
- 停止位元：1。
- 流量控制：None。
- TX 接轉接器 RX，RX 接轉接器 TX，GND 共地。
- 換行設定需符合程式接收格式。

### 操作流程
1. 連接硬體並開啟串口工具。
2. 選擇正確的 COM 埠。
3. 重設開發板，開始遊戲。
4. 輸入解除指令，觀察燈光與回傳訊息。
5. 分別測試成功、錯誤、逾時與按鈕停止功能。

## 7. 程式結構
- Core/Src/main.c：
  主程式、周邊初始化與遊戲控制邏輯。
- Core/Src/stm32g4xx_it.c：
  中斷處理入口。
- Core/Src/stm32g4xx_hal_msp.c：
  周邊底層時脈與 GPIO 設定。
- Core/Inc/：
  標頭檔與相關宣告。
- Drivers/：
  STM32 HAL 與 CMSIS 驅動。
- teat3.ioc：
  CubeMX 腳位、時脈與周邊設定。
- STM32G474RETX_FLASH.ld：
  Flash 連結配置。
- STM32G474RETX_RAM.ld：
  RAM 連結配置。
- docs/：
  實作照片與接線圖。

主迴圈處理狀態更新；中斷或回呼處理按鈕、
通訊與計時事件，實際分工以程式內容為準。

## 10. 已知限制
- 本專題為教學用遊戲模擬。
- 電腦使用的 COM 埠需依實際連線選擇。
- USART1 需確認外部接線，不能直接假設接上
  ST-LINK USB 就能使用。
- 更換 LED、蜂鳴器或腳位後，需同步修改接線、
  CubeMX 設定與程式。
- 實測結果與照片尚待補齊。
